## Projects

### AirMouse

A Windows app that turns a webcam into a touch-free mouse. MediaPipe hand
tracking drives the cursor through a self-scaling engage circle, with pinch
clicks, fist-armed swipe navigation, joystick scrolling, and a finger-count app
launcher. Python, OpenCV, and Windows SendInput through ctypes.

[Live page](https://radislavdenisenko.github.io/Portfolio/airmouse/) ·
[Source](https://github.com/RadislavDenisenko/AirMouse) ·
vendored here as `projects/airmouse`

### RoomMatch

scoring and listing search. In development, nothing worth linking yet.
