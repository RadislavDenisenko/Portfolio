AirMouse

Control the Windows mouse with hand gestures through a webcam. One hand moves the pointer, clicks, scrolls and sets the volume; the other is a four-slot app launcher. Nothing moves unless you're looking at the screen.

Python · MediaPipe · OpenCV · Win32 SendInput — Windows only, beta (v0.9.0)

How it works

Position, not velocity

Engaging locks an anchor circle sized to your hand as it appears on camera, so control feels identical whether you're sitting close or leaning back. Sensitivity ramps from the centre out to the rim — precise in the middle, fast at the edge — and pushing past the rim drags the circle along, so one motion crosses the whole screen.

Nothing fires by accident

Navigation has to be armed with a closed hand first, so an open hand moving quickly is only ever cursor motion. Arming keys off finger count rather than curl depth, which lets a loose, comfortable grab arm the gesture while a peace sign never does. The minimise gesture has to decelerate and land before it commits, so dropping your arm to rest doesn't minimise a window.

Cursor magnetism

Clickable things get sticky as the pointer nears them, which makes a small target like a window's close button easy to stop on. The pull is scaled to motion you're already making, so a still hand never drifts and sustained movement pushes straight through. Targets come from window caption buttons, classic Win32 controls, and accessibility queries for apps that draw their own UI.

It stops when you look away

A face-landmark model runs alongside the hand tracker and checks head yaw and pitch. Turn to talk to someone and control pauses; look back and it resumes. It's deliberately forgiving — glancing at the edge of a monitor still counts as looking — and a held drag survives a quick glance away before being released safely.

Run it

You'll need Windows, a webcam and Python 3.12. There's no packaged installer yet — it runs from source. 

git clone https://github.com/RadislavDenisenko/AirMouse.git
cd AirMouse
python -m venv venv
venv\Scripts\python.exe -m pip install -r requirements.txt
run_airmouse.bat

A small always-on-top preview shows what the tracker sees. If it reports that the camera is busy, close whatever else is holding the webcam — Discord, Zoom, Teams, a browser tab — and start it again. Press B for settings, D for the live gesture debug readout, Q to quit.

Known limitations

Windows only — the cursor is driven through the Win32 SendInput API.

Needs reasonable light. In a dim room the camera stretches its exposure and drops to ~8 fps, so the app forces a short manual exposure to hold 30.

Only one application can hold the webcam at a time.

Magnetism only sees controls an app exposes to Windows. Games and custom-drawn UIs expose nothing, so it quietly does nothing there.
